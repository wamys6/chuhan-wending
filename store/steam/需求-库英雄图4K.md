## 一、为什么还要再出一张

| | 现在手上这张 | 要求 |
|---|---|---|
| 原生尺寸 | **2172 × 724** | **≥ 3072 宽** |

但 4K 屏全屏库页会明显发虚，而这是玩家看到的**第一张官方图**。

**判据只有一条：原生宽度 ≥ 3072。** 其他都不用改。

## 二、必须满足的硬条件

### 1. 分辨率（本次唯一的改动点）

| 项 | 要求 |
|---|---|
| 目标成品 | 3840 × 1240 = **3.097 : 1** |
| 首选出图 | 3:1（**3072×1024** 或 **4096×1365**），差 3% 由脚本按宽贴合裁高，只裁 1% 高度 |
| 次选 | 21:9 → 裁到 3.097 会切掉 **25%** 高度，构图上下各留 15% 余量 |
| 不要用 | 16:9 → 裁掉 **43%** 高度，人物必被切 |
| 底线 | **原生宽度 < 3072 直接判不合格**，不管画得多好 |

> 生图模型给不了精确像素，必须走「高清 / 超分 / 4K 直出」那一档，或者换支持大图直出的模型。

### 2. 构图（照抄，不要自由发挥）

- **画面左侧 40% 必须是空白宣纸。** 没有人物、没有马、没有甲片、没有重墨块，只能有极淡的飞白粉尘和一两滴散落墨点。这块地方要叠发行商 Logo。
- **主体只住在 x 52%–92%、y 13%–87% 之内。** 上 13% 和下 13% 只允许纸色和雾，这样脚本重新裁高时不会切到人。
- 任何重要元素都不碰画面四边。

### 3. 不要做的事

- ❌ 不要写任何字、印章、水印、签名。**中文标题一律由脚本排**，模型写必出错字。
- ❌ 不要往左侧空白里"补背景"。空白就是设计。
- ❌ 不要换成写实笔触。上一版马头、甲片画得很细，但丢了水墨炸裂感，和同套的胶囊图（同一屏会出现）不像一个项目。
- ❌ 不要加边框、UI、现代物件。

