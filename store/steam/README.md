## 截图说明

`--tour` 渲出的是 1920×1055（窗口被任务栏挤掉 25px），这里统一 LANCZOS 放大到 1920×1080
（纵向 +2.4%，无可见形变），满足 Steam 的 1920×1080 最低要求。若要零缩放，需在无任务栏的
环境用 1920×1080 全屏重拍。

选图逻辑（第一屏 4 张最重要）：战斗 → 战役地图 → 奖励三选一 → 军师三选一 → 事件 → 图鉴。

## 重新生成

```bash
# 1) 先出截图（非 headless，需要真实渲染）
env -u ELECTRON_RUN_AS_NODE "D:/godot/Godot_v4.7.2-stable_win64.exe" \
  --path godot --resolution 1920x1080 -- --tour
# 2) 合成胶囊与截图规范化
python tools/make-steam-art.py
```

## 设计约束（改图时别踩）

- **缩略尺寸优先**：小胶囊实际显示可低至 120×45，标题必须在这个尺寸下认得出来；
  每次都把 `_test-small-231x87.png` 重新生成并肉眼看一遍。
- **不要用截图做胶囊**：缩略后必糊，Steam 也不建议。
- **头图不是主胶囊的裁切**：905 高裁到 430 会把两颗头都切掉，必须独立构图。
- **边缘留安全区**：Steam 会在四角压折扣角标与徽章，标题与脸都不要贴边。
