## 二、必须满足的硬条件

### 1. 分辨率（本次唯一的改动点）

| 项 | 要求 |
|---|---|
| 目标成品 | 3840 × 1240 = **3.097 : 1** |
| 首选出图 | 3:1（**3072×1024** 或 **4096×1365**），差 3% 由脚本按宽贴合裁高，只裁 1% 高度 |
| 次选 | 21:9 → 裁到 3.097 会切掉 **25%** 高度，构图上下各留 15% 余量 |
| 不要用 | 16:9 → 裁掉 **43%** 高度，人物必被切 |
| 底线 | **原生宽度 < 3072 直接判不合格**，不管画得多好 |

> 生图模型给不了精确像素，必须走「高清 / 超分 / 4K 直出」那一档，或者换支持大图直出的模型。

### 2. 构图（照抄，不要自由发挥）

- **画面左侧 40% 必须是空白宣纸。** 没有人物、没有马、没有甲片、没有重墨块，只能有极淡的飞白粉尘和一两滴散落墨点。这块地方要叠发行商 Logo。
- **主体只住在 x 52%–92%、y 13%–87% 之内。** 上 13% 和下 13% 只允许纸色和雾，这样脚本重新裁高时不会切到人。
- 任何重要元素都不碰画面四边。

### 3. 不要做的事

- ❌ 不要写任何字、印章、水印、签名。**中文标题一律由脚本排**，模型写必出错字。
- ❌ 不要往左侧空白里"补背景"。空白就是设计。
- ❌ 不要换成写实笔触。上一版马头、甲片画得很细，但丢了水墨炸裂感，和同套的胶囊图（同一屏会出现）不像一个项目。
- ❌ 不要加边框、UI、现代物件。

## 七、执行记录（2026-11-07）

### 7.1 做法

```
2172×724  --Real-ESRGAN x4-->  8688×2896  --LANCZOS 0.442×-->  3840×1280  --裁高 20/20-->  3840×1240
```

工具 `realesrgan-ncnn-vulkan` v0.2.5.0（GitHub release，约 45MB），模型 `realesrgan-x4plus`，
GTX 1060 上 32 秒/张。封装成 `tools/upscale-hero.py`，产物落在 `store/steam/_art/_raw4k/`，
`make-steam-art.py` 的 `hero_src()` 宽度 ≥3000 就优先用它。

### 7.2 为什么用 photo 模型而不是 anime 模型

先用 `realesrgan-x4plus-anime`（直觉上「插画向」该更合适），实测**反了**：

| | 空白纸面 | 旗面墨晕边缘 | 甲片 |
|---|---|---|---|
| LANCZOS（旧） | 有细颗粒 | 柔和过渡 | 糊 |
| anime x4 | **被削成一片平涂**，纸纹消失 | **发硬、有台阶** | 锐但脆 |
| photo x4 | 保留并略微强化纸纹 | 保持柔和 | 锐且保留笔触 |

水墨画靠的就是墨晕的柔和过渡和纸的颗粒感，anime 模型把这两样当噪声抹掉，方向错了。

### 7.3 三个已证伪 / 已验证的点

- **`-s 2` 不能用**：ncnn 版在 -s 2 下 tile 拼接错位，输出是拼贴画（整幅错位、右半幅叠到左半幅）。必须用模型原生 `-s 4`，再自己缩。
- **TTA（`-x`）没有收益**：`mean|diff|=1.23 / 255`，灰度相关 0.999378，肉眼无差异，代价是 8× 时间（32s → 4min）。不启用。
- **构图零位移**：新旧 `library-hero-charge.png` 相位相关位移 `dy=0, dx=0`，灰度相关 0.9962，差异只在锐度。所以「构图照抄」这一条成立。
