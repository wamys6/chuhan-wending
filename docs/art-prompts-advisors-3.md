## 一、先看这三点

1. **尺寸 1024×1024 方图**。军师卡里显示为 **160×160 的方形**（`COVER` 铺满，无圆角裁切），
   所以和事件图的「圆形窗」不同——四角不会被切，但也别在角上放细节。
2. **构图：大半身、头在画面上 1/3**。缩到 160px 时只看得出「人 + 一两个道具 + 背景氛围」，
   别画全身远景，别在一张图里塞三个叙事点。
3. **画风沿用卡牌模板**，只把竖幅改方形。三张并排在选择页上，色温要一致（都偏冷灰 + 淡赭），
   不要一张暖黄一张冷蓝，否则并列时像三个游戏。

## 六、出图之后怎么接入

1. 三张按上表命名放进 `godot/assets/cards/`（和卡牌、事件图同一个目录）。
2. **先把 `.import` 改成有损再导**，否则每张会多占约 2.5MB：
   把 `compress/mode=0` 改成 `1`、`lossy_quality` 改成 `0.8`（与现有 104 张一致）。
3. `godot --headless --path godot --import`
4. 跑 `art_rect_test`（它有一条「周勃无立绘走兜底」的断言，补图后要同步改成检查真图）。

代码侧不需要动：`advisor.gd` 用 `UiTheme.art_texture("ad_" + id)` 按文件名直接取，
取不到才走朱砂单字兜底。
