# 真人体验验收清单

> 目的：把「数值全绿但玩起来不对劲」的东西捞出来。AI 能自查的（文字溢出、字号、
> 回归）都已经量完并钉了断言，这份清单只列**需要真人才能判断**的事。
> 预计总用时：第一轮 30~40 分钟 + 第二轮 20~30 分钟。

---

## 怎么用

- **程序**：`export/ChuHanWenDing.exe`（最新版，145.7 MiB）。
- **分辨率**：如果你主力屏是 1080p 以上，请额外把窗口缩到约 1366×768 过一遍第二轮——
  最近一轮小屏可读性改动都是按这个尺寸量的，你的体感是最后一道验收。
- **两轮节奏**：
  - **第一轮（中文，裸玩）**：不看清单，从新档打到第 3 关或阵亡，随手记直觉。
    直觉比清单值钱——清单能查「放不放得下」，查不到「烦不烦」。
  - **第二轮（照单过）**：按下面的屏逐项核对，含英文界面。

**反馈格式**（一句话 + 截图即可，攒一起发我）：

```
[屏名] 现象一句话 ｜ 严重度：挡路 / 难受 / 无所谓 ｜ 截图
```

---

## 第一轮 · 裸玩（中文，30~40 分钟）

新建存档位 → 选初阵或常规 → 一路打到第 3 关左右。只记三件事：

1. **哪里让你犹豫超过 3 秒**（看不懂、找不到、不知道按什么）；
2. **哪里让你烦**（重复点击、等待、文字读不完）；
3. **哪一刻你觉得「有点意思」**——这个和问题一样重要，我要知道哪里做对了。

---

## 第二轮 · 按屏过

### 1. 主菜单（1 分钟）

- [ ] 标题、按钮、版本号在 1366 宽下都完整
- [ ] 侧边立绘不挡按钮、不抢视线

### 2. 存档位（2 分钟）

- [ ] 三个槽的说明文字完整（切英文再看一遍——这里刚修过「英文被截成半句话」）
- [ ] 有档/空档两种状态都顺眼
- [ ] 删档确认不会误触

### 3. 战役流程（8 分钟）

**军师 3 选 1**
- [ ] 三张军师卡名字、被动描述在 1366 下放得下
- [ ] 被动文案能看懂要怎么做才触发

**行军事件**
- [ ] 事件标题、正文、选项文字完整
- [ ] 选项代价/收益的表述不歧义

**奖励三选一**
- [ ] 三张奖励卡齐全、不挤
- [ ] 「同名 ≤2」之类规则如果界面上有，看得懂

**关卡目标条（重点，刚改过）**
- [ ] 目标文字最多两行，不碰军阵区
- [ ] 8 关里随意挑 3 关看，英文也切一下

**解锁提示**
- [ ] 解锁新军师/新事件时的横幅清晰、不遮地图标题（英文下尤其注意——之前发现过横幅压标题）

### 4. 战斗（10 分钟，核心）

- [ ] **三列军阵**：敌我列位一眼分得清
- [ ] **战报**：抬头单行、正文折行可读；打快了战报不会糊成一团
- [ ] **军师主动技按钮**（操作栏最左）：状态清晰——可用/已用/不适用三种一眼分得清
- [ ] **关键词印**（卡面右上角）：冲锋/死战/连击的印不糊、不挡牌名
- [ ] **牌库/疲劳可见化**：牌库剩余、疲劳跳字看得到
- [ ] **敌方意图预告**：能据此做决策（这是它存在的唯一理由）
- [ ] **主将卡**：双方血量、英文名（`Hegemon-King`）、敌将提示（`Click to attack`）完整
- [ ] **牌名两行的卡**：图鉴/手牌里留意窄牌名的卡（英文下会断两行），第二行不被切、不压属性
- [ ] 出牌→拖拽/点击的手感，动画节奏不拖

### 5. 结局与重整（2 分钟）

- [ ] 胜利/失败结算清楚：死在哪、差多少
- [ ] **重整**（每关 1 次）：触发时机、提示明显；用掉后「二败即终」的规则有感知

### 6. 图鉴（3 分钟）

- [ ] 卡片/军师/事件三个分页切换正常
- [ ] 左栏统计文字不被截
- [ ] 网格里牌名不压到隔壁卡

### 7. 设置（2 分钟）

- [ ] **切英文再切回中文**：所有已打开的界面文字都跟着变（这是「切语言救不了历史文本」的坑，重点看战报这类历史内容，行为应该是「新生成的跟随新语言」）
- [ ] 音量 sliders 生效
- [ ] 设置改完重开程序，还保留

### 8. 快速开战 + PvP（5 分钟，可跳过）

- [ ] 单局对战进出正常
- [ ] PvP：建房/加入/断线表现（**断线重连真机双客户端**是你记录在案的自测项，有条件就一起做）

## 已知且刻意不动（别报，省你时间）

| 现象 | 原因 |
|---|---|
| 战报正文多数折两行 | 要放宽得动左栏栅格，等这轮真人反馈一起定 |
| 第 8 关很难（带重整约 72% 通过） | 设计门槛，全游戏唯一「卡点」 |
| 第 7 关三重惩罚（18 血/手牌 4/敌 +2 粮） | 实测过，带重整口径下影响只有 +1.5pp，保留 |
| 商店截图每次重合成内容微变 | 巡览随机取图，与游戏本体无关 |
| AI 超分的 4K 图最高频细节「过于清楚」 | 重建特性，已在交付说明声明 |
